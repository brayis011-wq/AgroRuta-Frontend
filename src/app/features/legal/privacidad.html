AgroRuta es una aplicación para administrar fincas, cultivos, trabajadores y nóminas. Esta política explica qué datos guardamos, para qué los usamos y qué puedes hacer con ellos.

Qué datos guardamos

  • Tu cuenta: nombre, correo, teléfono y foto de perfil (si la agregas). La contraseña se guarda cifrada; nadie puede leerla.
  • Lo que registras: fincas, lotes y su ubicación, siembras, fumigaciones, labores, cosechas, trabajadores, jornales, nóminas y pagos.
  • Trabajadores: los datos que el agricultor registra (nombre, cédula, teléfono). Si el trabajador crea su cuenta, ve solo sus propios jornales, nóminas y pagos.

Para qué los usamos

  • Para que la aplicación funcione: mostrar tus datos, calcular costos, generar reportes y nóminas.
  • Para consultar el clima de tus fincas con su ubicación.
  • Para enviarte correos: recuperar la contraseña, avisos de seguridad, solicitudes y pagos de trabajadores, y el resumen diario del cultivo. Los correos opcionales se pueden apagar en Configuración.

No vendemos ni compartimos tus datos con terceros para publicidad.

Correos con Gmail

AgroRuta envía los correos desde su propia cuenta de Gmail usando la API de Gmail, con permiso solo para enviar mensajes. No lee, guarda ni accede a tu bandeja de correo. El uso de la información recibida de las APIs de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Servicios que usamos

  • Alojamiento de la aplicación y de la base de datos en servicios en la nube.
  • OpenWeather, para el pronóstico del clima (solo recibe coordenadas, no datos personales).
  • Gmail, para enviar los correos.

Seguridad y copias

La conexión es cifrada (HTTPS), las contraseñas se guardan con un cifrado de una sola vía y se hacen copias de seguridad cifradas de la base de datos.

Tus derechos

Puedes consultar y corregir tus datos desde tu perfil, y pedir que se eliminen escribiendo al correo de contacto. Esto aplica según la Ley 1581 de 2012 de protección de datos personales de Colombia.

Contacto

Para cualquier pregunta sobre tus datos, escribe al correo de soporte de AgroRuta.
